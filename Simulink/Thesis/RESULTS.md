# 졸업논문 결과 정리 (DAB TPS, 통합 E2E 회귀 제어기)

이 파일은 루프가 결과를 얻을 때마다 누적한다. 수치는 모두 해석 모델(`tps_model.py`, 이상 소자, V1 = 380 V,
n = 4, L = 90 µH, fs = 80 kHz) 기준이다. Simulink 자체 실행(T6)은 MATLAB 라이선스 문제로 아직 못 했다.
그 대신 .slx에서 추출한 비이상 Python 플랜트로 검증하고 있다(8절).
ΔI = Ipk(SPS) − Ipk(제어기) (양수 = 저감), D0는 PI가 닫는다고 보고 PI 정상상태 = 첫 교차점으로 평가한다.

## 1. 최적 제어 곡면과 매끄러움 (T0b, T1)

- 점별 최적(v1, `optimal_surface.py`): 격자 |P| 0–1200 W(25 W) × V2 84–109.2 V(1.2 V)에서 SPS 대비 평균 −0.099 A,
  최대 −1.578 A(V2 = 109.2 V, |P| = 0), SPS보다 나쁜 점 0. 이득은 경부하·k ≠ 1에 몰려 있고 k ≈ 1(V2 ≈ 95 V)에서는 ≈ 0.
- **거칠기의 원인**: (|P| = 0, k = 1)이 특이점이다. k ≠ 1이면 경부하 최적 D는 D_min으로 가고, k = 1이면 모든 |P| > 0에서
  SPS가 최적이라 전이 구간 폭이 k → 1에서 0으로 줄어든다. v1(허용집합 ICM)의 인접 최대 변화 0.245는 V2 = 94.8 V,
  |P| 0 → 25 W에서 나온다. 인접 변화 > 0.04인 곳은 모두 |P| ≤ 175 W(V2 84–102 V)에 있고, > 0.1인 곳은 모두
V2 92.4–97.2 V, |P| ≤ 75 W에 있다.
- **곡면 v2** (`smooth_surface_v2.py`): Ipk 손실(연성) + 모델 좌표 기울기 제곱 벌점(λ), SPS 열화는 하드 금지.
  λ 스윕으로 매끄러움–최적성 파레토 곡선을 얻었고 λ = 5e-3을 택했다.

## 3. 제안 제어기 Smooth RegHDC와 비교 평가 (T3–T5, T9)

**구조**: (|P|, V2) → 정규화 → 고정 무작위 사상 h = √2·cos(xW + b) (D = 256, σ = 0.1; HDC의 연속 부호화) → 선형
읽기층 → Δ = softplus_τ(y) (τ = 0.004) → D1, D2 = 0.5 − Δ. 분류기·FSM 없이 SPS 영역(Δ ≈ 0)과 TPS 영역을 한 식으로 덮고,
곡면은 무한히 매끄럽다. D0는 PI가 닫는다.

**학습** (`train_e2e.py`):
- (a) T1 곡면(λ = 2e-3)을 ridge로 적합. 초매개변수는 D RMSE가 아니라 **무작위 4000점에서 PI 정상상태 Ipk**로 골랐다.
- (b) 물리 내장 E2E 미세조정: 무작위 (|P|, V2) 배치에서 PI 정상상태 Ipk − Ipk_SPS를 직접 최소화하고, SPS 열화(힌지),
  전력 미달, 야코비안 거칠기에 벌점을 준다. 기울기는 전력 제약에 대한 암시 함수 정리
  dIpk/dD = ∂Ipk/∂D − (∂Ipk/∂φ)(∂P/∂D)/(∂P/∂φ)로 구했다. 근을 다시 풀 필요가 없고, φ를 다시 풀어 구한 유한차분과
  일치함을 확인했다(`test_train_e2e.py`). 읽기층만 학습하고 부호화(W, b)는 고정했다.
- 6개 변형(`train_e2e_b*_hist.csv`). b*는 검증 점수로 골랐고, 열화 힌지 가중을 20으로 두어 b3(β = 20)이 선택됐다.

**시험 결과** (`evaluate.py`, `out/eval_table.csv`): 학습·선택에 쓰지 않은 무작위 1만 점(seed 2026). 기준 최적은

## 5. 공정 비교: LUT에도 같은 물리 E2E 학습 (T13, `train_lut_e2e.py`)

쌍선형 LUT의 각 칸 값을 학습 변수로 두고 `train_e2e.py`와 같은 손실·기울기·검증 선택을 적용했다(암시 함수 기울기 ×
쌍선형 가중치, 칸 단위 기울기 벌점, 매 단계 [D_min, 0.5] 투영, 칸마다 균등 표본을 뽑는 층화 배치). 기울기는 유한차분과
상대오차 2e-3 이내로 일치했다(`test_train_lut_e2e.py`). 결과는 3절 표의 아래쪽 다섯 줄이다.

- **같은 학습을 쓰면 LUT도 제안 모델과 같은 성능을 낸다.** 49×22 LUT + E2E는 평균 0.0815 A(b3와 같음), 최악 −0.9 mA다.
  곡면 없이 SPS에서 출발한 L49s3도 같은 평균에 최악 −0.2 mA로, 표 전체에서 최악점이 가장 좋다.
- 같은 메모리(약 1.1–1.3 kB)에서도 비슷하다. LUT 25×11 + E2E(1116 B)는 0.0813 A / −5.6 mA, 제안 구조 D = 64(1288 B)는
  0.0812 A / −6.1 mA다. 328 B(13×6)까지 줄이면 0.0804 A이고 0.25 % 점이 SPS보다 5 mA 넘게 나빠진다.
- **정직한 결론**: 2입력 문제에서 성능을 좌우하는 것은 파라미터화(HDC냐 LUT냐)가 아니라 **PI 정상상태를 직접 최소화하는
  물리 내장 E2E 학습**(암시 함수 기울기)이다. 논문의 기여도 이 학습법, 단일 회귀(분류기·FSM 없음), 어디서도 SPS보다
  나쁘지 않다는 보장으로 서술해야 한다. HDC(무작위 푸리에 부호화) 구조의 장점은 C∞ 곡면과 미분 가능한 야코비안(LUT는
  칸 경계에서 C0)이다. 메모리·성능상의 우위는 2입력에서는 없다.

## 6. HV 링크 전압 V1 변동과 물리 정규화 입력 (T14 축소, `v1_invariance.py` → `out/v1_invariance.log`)

이상 DAB에서는 i_L = V1/(ωL)·F(θ; k, D0, D1, D2), P = V1²/(ωL)·G(k, D)이고 k = nV2/V1이다(무작위 2000점에서 수치 확인,
오차 7e-15 A). 따라서 (|P|, V2, V1)의 최적 (D1, D2)는 V1 = 380 V에서의 등가점 V2' = V2·380/V1, |P|' = |P|·(380/V1)²의
최적과 같다. 3입력 HDC로 메모리 장점을 보이려던 실험은 이상 모델에서는 의미가 없다. 세 번째 입력이 사라지기 때문이다.
대신 V1이 380 V에서 벗어날 때의 강건성을 확인했다(V1 361–399 V(±5 %), 무작위 6000점).

| b3 입력 | 평균 ΔI [A] | 최악 [mA] | 5 mA 초과 열화 | 0.1 mA 초과 열화 |
|---|---|---|---|---|
| 원 입력 (\|P\|, V2) — V1 무시 | 0.0802 | −302 | 9.45 % | 17.1 % |
| **물리 정규화 (\|P\|', V2')** | **0.0908** | **−2.4** | **0 %** | 0.20 % |

V1을 무시하면 k = 1 능선이 실제와 다른 V2에 놓여 k 0.92–1.07에서 SPS보다 나빠진다. 정규화 입력은 재학습 없이 이를 없앤다.
`smooth_reghdc_infer.m`(선택 인수 V1)과 C 내보내기(`smooth_reghdc_v1_equiv()`)에 반영했다. 비이상성(데드타임, 저항)은 이
스케일링을 조금 깨므로, 진짜 3입력 모델이 메모리값을 할 여지는 그쪽에만 있다.

## 7. ZVS(부가 지표, T11, `zvs.py` → `out/zvs.log`)

제어기는 Ipk를 최소화하며 스위칭 손실은 목표가 아니다. 레그별 턴온 순간 전류 부호로 ZVS를 판정했다(시험 1만 점, 이상 모델,
PI 정상상태). I_min은 Coss를 충전하는 데 필요한 전류로, 이 플랜트에서는 미상이다.

| 제어기 | 전 레그 ZVS (I_min 0) | \|P\| < 300 W | 0.95 ≤ k ≤ 1.05 | 전 레그 ZVS (I_min 0.5 A) |
|---|---|---|---|---|
| SPS | 74.6 % | 23.4 % | 90.7 % | 64.7 % |
| ICROS2026 곡면 | 50.9 % | 3.6 % | 55.8 % | 45.7 % |
| LUT v2 49×22 | 81.5 % | 47.0 % | 89.9 % | 62.2 % |
| **제안 b3** | 78.8 % | 39.8 % | 91.7 % | 63.4 % |
| 점별 최적 | 87.9 % | 60.8 % | 94.9 % | 62.1 % |

TPS는 경부하 ZVS 영역을 넓힌다(SPS 23 % → b3 40 %). 다만 Ipk를 낮추는 TPS는 스위칭 순간 전류도 작다. 그래서 0.5 A 여유를
요구하면 모든 제어기가 62–65 %로 비슷해진다. ZVS를 보장하려면 별도 제약이 필요하다. 이는 향후 과제로 남긴다.

**Python 플랜트** (`plant_full.py`, 검사 `test_plant_full.py` ALL PASS): 위 요소를 모두 넣은 전체 주기 슈팅

**(1) 정상상태 데이터로 검증** (`validate_plant.py`): 데이터셋에서 D0 라벨이 +90°인 행은 마지막 계단이라 D0가 고정된
정상상태다. 300점 예비 결과는 다음과 같다.
- 이상 해석 모델: Ipk 바이어스 −0.135 A, RMSE 0.238 A, R² 0.994
- Python 플랜트(Ron 52 mΩ): +0.052 A, 0.150 A, R² 0.9975

**정상상태에서는 해석 모델도 Simulink와 0.1–0.2 A 수준으로 맞는다.** Simulink 손실(11.8 %)은 플랜트가 아직 덜 잡는다
(다이오드·채널 분담 모델링에 민감).

**(2) 데이터셋 생성 과정 재생** (`transient_replay.py`): 44 ms 계단 실행을 주기 단위로 재생하고 같은 창(0.1 ms)으로
추출해 데이터셋과 비교했다. D0 적용 방식에 대해 두 가설을 시험했다. 40개 조합 예비 결과와 2000개 조합 ZOH 결과는 다음과 같다.

| 재생 가설 | Ipk 바이어스 | Ipk RMSE | P(라벨 69.35°)/P(라벨 90°) 중앙값 |
|---|---|---|---|
| (참고) 라벨 D0의 이상 정상상태 | −0.88 A | 1.48 A | — |
| ZOH (각 창이 자기 라벨, 2000 조합) | −0.81 A | 1.40 A | 0.952 |
| **선형보간 (D0가 다음 라벨로 램프 중, 40 조합)** | **+0.08 A** | **0.52 A** | **0.9986** |
| 데이터셋 | | | 0.9994 |

**결론(예비)**: 기존 데이터셋은 From Workspace가 D0를 **선형보간**한 상태에서 측정됐다. 각 창은 자기 라벨이 아니라
다음 라벨 쪽으로 약 95 % 진행한, 아직 움직이는 D0를 본다. 해석 모델과 데이터셋의 큰 차이(평균 −0.88 A, RMSE 1.48 A)와

1 ms 계단 과도 DC 오프셋 가설은 기각된다(직렬 C와 1.4–1.8 Ω 루프 저항으로 τ ≈ 0.1 ms라 1 ms 안에 정착).

**(3) 판정 실행 중** (`plant_verdict.py`, 양자화 없이: 100 ns 격자는 Simulink 제어기 모델의 산물이고 MCU HRTIM은 184 ps):
