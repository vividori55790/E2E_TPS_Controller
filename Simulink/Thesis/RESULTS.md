# 졸업논문 결과 정리 (DAB TPS, 통합 E2E 회귀 제어기)

이 파일은 루프가 결과를 얻을 때마다 누적한다. 수치는 모두 해석 모델(`tps_model.py`, 이상 소자, V1 = 380 V,
n = 4, L = 90 µH, fs = 80 kHz) 기준이다. Simulink 자체 실행(T6)은 MATLAB 라이선스 문제로 아직 못 했다.
그 대신 .slx에서 추출한 비이상 Python 플랜트로 검증하고 있다(8절).
ΔI = Ipk(SPS) − Ipk(제어기) (양수 = 저감), D0는 PI가 닫는다고 보고 PI 정상상태 = 첫 교차점으로 평가한다.

## 1. 최적 제어 곡면과 매끄러움 (T0b, T1)

- 점별 최적(v1, `optimal_surface.py`): 격자 |P| 0–1200 W(25 W) × V2 84–109.2 V(1.2 V)에서 SPS 대비 평균 −0.099 A,
  최대 −1.578 A(V2 = 109.2 V, |P| = 0), SPS보다 나쁜 점 0. 이득은 경부하·k ≠ 1에 몰려 있고 k ≈ 1(V2 ≈ 95 V)에서는 ≈ 0.
- **거칠기의 원인**: (|P| = 0, k = 1)이 특이점이다. k ≠ 1이면 경부하 최적 D는 D_min으로 가고, k = 1이면 모든 |P| > 0에서
  SPS가 최적이라 전이 구간 폭이 k → 1에서 0으로 줄어든다. v1(허용집합 ICM)의 인접 최대 변화 0.245는 V2 = 94.8 V,
  |P| 0 → 25 W에서 나온다. 인접 변화 > 0.04인 곳은 모두 |P| ≤ 175 W(V2 84–102 V)에 있고, > 0.1인 곳은 모두
V2 92.4–97.2 V, |P| ≤ 75 W에 있다.
- **곡면 v2** (`smooth_surface_v2.py`): Ipk 손실(연성) + 모델 좌표 기울기 제곱 벌점(λ), SPS 열화는 하드 금지.
  λ 스윕으로 매끄러움–최적성 파레토 곡선을 얻었고 λ = 5e-3을 택했다.

## 3. 제안 제어기 Smooth RegHDC와 비교 평가 (T3–T5, T9)

**구조**: (|P|, V2) → 정규화 → 고정 무작위 사상 h = √2·cos(xW + b) (D = 256, σ = 0.1; HDC의 연속 부호화) → 선형
읽기층 → Δ = softplus_τ(y) (τ = 0.004) → D1, D2 = 0.5 − Δ. 분류기·FSM 없이 SPS 영역(Δ ≈ 0)과 TPS 영역을 한 식으로 덮고,
곡면은 무한히 매끄럽다. D0는 PI가 닫는다.

**학습** (`train_e2e.py`):
- (a) T1 곡면(λ = 2e-3)을 ridge로 적합. 초매개변수는 D RMSE가 아니라 **무작위 4000점에서 PI 정상상태 Ipk**로 골랐다.
- (b) 물리 내장 E2E 미세조정: 무작위 (|P|, V2) 배치에서 PI 정상상태 Ipk − Ipk_SPS를 직접 최소화하고, SPS 열화(힌지),
  전력 미달, 야코비안 거칠기에 벌점을 준다. 기울기는 전력 제약에 대한 암시 함수 정리
  dIpk/dD = ∂Ipk/∂D − (∂Ipk/∂φ)(∂P/∂D)/(∂P/∂φ)로 구했다. 근을 다시 풀 필요가 없고, φ를 다시 풀어 구한 유한차분과
  일치함을 확인했다(`test_train_e2e.py`). 읽기층만 학습하고 부호화(W, b)는 고정했다.
- 6개 변형(`train_e2e_b*_hist.csv`). b*는 검증 점수로 골랐고, 열화 힌지 가중을 20으로 두어 b3(β = 20)이 선택됐다.

- **E2E 단독으로도 된다**: 곡면이나 데이터셋 없이 SPS에서 출발해 물리 손실만으로 학습한 b5가 0.0807 A(최적의 98.5 %)에
  도달했고, 더 매끄럽다(0.086).
- **정직한 비교 (중요)**: 2입력 문제에서는 T1 곡면을 같은 메모리 LUT(49×22)로 저장해도 거의 같은 결과가 나온다
  (0.0812 vs 0.0815 A, 열화 둘 다 0, LUT가 약간 더 매끄러움). 제안 모델의 우위는 성능 숫자보다 다음 세 가지에 있다:
  (1) 물리 손실로 직접 학습할 수 있다, (2) 미분 가능한 매끄러운 곡면이다, (3) 입력 차원이 늘 때 메모리가 선형으로 는다.
  (3)을 보이는 실험(V1 입력 추가, T14)과 LUT에도 E2E를 적용한 공정 비교(T13)를 했다. 결과는 아래 5절과 6절에 있다.
  요약하면 (1)의 E2E 학습은 LUT에도 똑같이 통하고, (3)은 이상 모델에서는 V1이 스케일링으로 소거돼 성립하지 않는다.

**MCU 배포물 (T9, `export_mcu.py`)**: `out/SmoothRegHDC_STM32.h`, `out/smooth_reghdc.c/.h`. float32 경로(5128 B)와
int16 경로(4618 B)를 낸다. int16 경로는 W를 2^-12 회전 단위로 두어 uint32 랩어라운드가 곧 mod 2π가 되게 했고,
Q15 cos 표(1025개, 선형보간)와 int64 MAC을 쓴다. float64 모델 대비 max|ΔD|는 2.7e-4(int16), 5.6e-7(float32)이다.
연산량은 차원당 MAC 4회 + 표 보간이다. 이 PC에는 C 컴파일러가 없어 C 파일 자체는 컴파일하지 못했다. 평가표의 int16 행은
C 코드를 한 연산씩 따라가는 Python 에뮬레이션 결과다.

  짝지어 본문(1.222 A)과 다르다. 이 데이터셋에서 가장 큰 저감은 P −150 W / V2 110 V(데이터셋 SPS 4.736 A)에서 나온다.

  1.686 A다(SPS 2.429 A, 최대 저감 0.743 A, `icros_max_check.py` → `out/icros_max_check.log`). 200 W / 110 V도 같다(1.515 A가
  필요하지만 최적은 1.946 A). 따라서 **3.392 A는 정상상태에서 도달할 수 없는 값이다.** 이 운전 범위에서 단일 점 최대 저감의
  상한은 1.2–1.6 A이고, 경부하·V2 가장자리에서 나온다(50 W / 110 V 1.224 A, 0 W / 109.2 V 1.578 A). 비이상 플랜트에서도 V2 =
  109.2 V의 이득은 이상 모델과 +0.04 A 안에서 같다(8절 판정 A).
- k ≈ 1 부근(V2 90–100 V)에서는 ICROS2026의 "최적" (D1, D2)가 정상상태에서 오히려 SPS보다 피크 전류를 키운다.
  이것이 사용자가 기존 데이터에서 본 k ≈ 1 이득의 정체일 가능성이 높다. **최종 판정은 Simulink 정상상태(T6)로 한다**:

## 5. 공정 비교: LUT에도 같은 물리 E2E 학습 (T13, `train_lut_e2e.py`)

## 9. 데드타임 견고 학습: SPS 이탈 비용 (T7, `train_e2e.py --margin`) — 플랜트 평가 진행 중

**방법**: E2E 손실에서 각 점의 Ipk − Ipk_SPS에 이탈 비용 m·(1 − exp(−(Δ1 + Δ2)/δ0))를 더한다(주 항, SPS 열화 힌지, 검증 점수
모두). Δ = 0(정확히 SPS)이면 비용이 0이고, Δ가 δ0의 몇 배를 넘으면 m으로 포화한다. 따라서 제어기는 **예측 저감이 m보다 클 때만
SPS를 떠난다.** m은 플랜트에서 본 데드타임 불확실성(±20 mA)에 맞춰 25 mA로, δ0는 데드타임/주기(td·fs = 0.008)보다 작은
0.005로 두었다. 분류기나 임계값 분기는 없다. 같은 연속 회귀식에서 출력 softplus가 0으로 포화하는 영역이 넓어질 뿐이다.
기울기는 기존 암시 함수 기울기에 비용의 해석적 기울기를 더한 것이고, 유한차분과 상대오차 1.2e-4로 맞는다(`test_train_e2e.py`).

**학습 결과(이상 모델, 검증 4000점, b3에서 시작, 1200 step)**:

## 10. 졸업논문 장 구성 제안 (T10 초안)

1. **서론**: DAB와 피크 전류(소자 정격, 자성체, 손실). TPS의 필요성과 기존 접근(해석 최적화, LUT, 학습 기반).
   ICROS2026의 한계를 제기한다. 분류기 + 회귀 + FSM 구조, 입력 양자화로 생기는 계단 곡면, 과도 측정 데이터로 학습한 점이다.
2. **DAB TPS 정상상태 모델과 문제 정의**: 구간 선형 해석 모델(`tps_model.py`), 대칭성(최적 (D1, D2)는 |P|만의 함수),
   V1 스케일링(6절: 입력 정규화로 V1 소거), 제어 구조(회귀 = (|P|, V2) → (D1, D2), D0 = PI, 평가 = PI 정상상태 첫 교차점).
3. **최적 제어 곡면**: 점별 최적과 이론 한계(1절, k ≈ 1에서 이득 ≈ 0, 가장자리 최대 1.6 A), (|P| = 0, k = 1) 특이점,
   매끄러운 곡면 v2와 파레토(그림 `fig_surface_v1_vs_v2.png`, `fig_surface_v2_pareto.png`).
4. **제안 제어기 Smooth RegHDC**: 무작위 푸리에(HDC 연속) 부호화 + 선형 읽기 + softplus 출력(분류기·FSM 없는 단일 회귀),
   물리 내장 E2E 학습(PI 정상상태 Ipk를 직접 최소화, 암시 함수 기울기), 데드타임 견고 SPS 이탈 비용(9절), int16 MCU 구현(T9).
5. **검증**: (5.1) 공통 평가 1만 점과 조밀 격자에서 SPS, ICROS2026, Legacy RegHDC, LUT, LUT + E2E 비교(3, 5절, 그림
   `fig_eval_maps.png`, `fig_eval_slices.png`), (5.2) V1 강건성(6절), (5.3) ZVS(7절), (5.4) .slx 추출 비이상 플랜트 검증과
   판정(8절, 9절), (5.5) 기존 데이터셋과 ICROS2026 수치 재검증(라벨 오류, 3.392 A 도달 불가: 4절, 8절 (2)).
6. **결론과 한계**: 이득은 경부하와 k ≠ 1에 몰려 있다(전체 평균 0.08 A, 이득 구간 0.10 A, 최대 1.5 A). k ≈ 1에서는 이득이 없다.
   LUT 대비 우위는 파라미터화가 아니라 학습법(E2E)에 있다. Simulink 실측·실기 검증은 하지 못했다. Coss와 ZVS 여유도 한계로 남는다.

## 미해결 / 한계
- Simulink 자체 실행(T6/T8)은 MATLAB 온라인 라이선싱 때문에 데스크톱 로그온이 필요해 대기 중이다(8절). 그 대신 .slx에서
  추출한 Python 플랜트를 데이터셋의 정상상태 행(8000행, RMSE 0.18 A)과 생성 과정 재생(7.8만 행, RMSE 0.53 A)으로 검증하고
  판정에 썼다. 1–7절의 수치는 이상 소자 정상상태 모델 기준이다. 로그온하면 대화형 잡 `t6_verify`(데이터셋 시기 모델 복사본
  사용)가 자동으로 실행된다.
- 플랜트 검증 데이터는 고전력 정상 행뿐이다. k ≈ 1 경부하에서 데드타임이 만드는 ±20 mA는 어느 모델로도 확정할 수 없다.
  그래서 9절에서 이 크기의 이득은 포기하고 SPS를 유지하도록 설계했다. Simulink도 Coss = 0이라 실기의 데드타임 거동과 다르다.
- C 코드는 컴파일 검증 전이다(이 PC에 컴파일러 없음). Python 비트 단위 에뮬레이션으로만 확인했다.
